# Nexus (proyecto unificado)

Este repositorio consolida en un solo lugar los proyectos que antes vivian
sueltos: HiddenSignal, VCore Nexus / VCoreCore, Factory Engine Suite,
Nexus Design Dream (legado de Lovable) y Nexus Genesis (reconstruccion
independiente en Vite+React+TS). Cada uno vive en su propia carpeta de
nivel superior dentro de este repo, tal cual estaba, para revisar y
decidir que se queda, que se fusiona de verdad a nivel de codigo y que
se descarta.
