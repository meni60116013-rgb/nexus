# VECTOR-FORGE

Repositorio independiente para el desarrollo modular de una plataforma
software/hardware orientada a ingeniería, movilidad y herramientas digitales.

## Principios
- Offline-first cuando corresponda.
- Arquitectura modular.
- CI/CD exclusivamente mediante GitHub Actions.
- Sin compilaciones locales obligatorias.
- Artefactos reproducibles.
- Validación automatizada.
- Diseño preparado para expansión multiplataforma.

## Estructura

- `apps/` — aplicaciones cliente.
- `core/` — núcleo funcional.
- `packages/` — módulos reutilizables.
- `tests/` — pruebas.
- `docs/` — documentación.
- `scripts/` — automatización.
- `.github/workflows/` — CI/CD.
