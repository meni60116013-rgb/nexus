# Vehicle Creator UI — VCORE NEXUS

## Bloque

07/08 — Vehicle Creator UI

## Objetivo

Interfaz ligera para crear, modificar, visualizar y exportar
una configuración de motocicleta.

## Capacidades

- Identidad del vehículo
- Tipo de vehículo
- Geometría
- Masa
- Centro de gravedad
- Powertrain
- Performance
- Distribución estática de cargas
- Validación visual
- Persistencia local
- Exportación JSON

## Arquitectura

HTML5 + CSS + Vanilla JavaScript.

No requiere framework externo ni dependencia de compilación local.
