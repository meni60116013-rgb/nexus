# MOTORCYCLE CORE — VCORE NEXUS

Especialización del Universal Vehicle Core para motocicletas.

## Capacidades

- Identidad de motocicleta
- Configuración geométrica
- Wheelbase
- Radio de ruedas
- Steering geometry
- Trail
- Masa
- Powertrain básico
- Suspensión delantera y trasera
- Snapshot universal de motocicleta
- Validación determinista
- Adapter Vehicle Core -> Motorcycle Core

## Integración

Universal Vehicle Core
        ↓
Motorcycle Core
        ↓
Vehicle Systems
        ↓
Engineering Engine
        ↓
Vehicle Creator / Demonstrator
